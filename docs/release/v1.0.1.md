# iqdb-eval v1.0.1

A fix release. No API changes.

## Fixed

- **No silent id truncation in ground truth.** `compute_ground_truth` cast
  `VectorId::U64` ids to `u32`, so an id above `u32::MAX` became a different
  id and recall was scored against the wrong neighbours (an exact index could
  score zero against itself). Ground truth is 32-bit, like the `.ivecs`
  format, so such an id now returns `EvalError::UnsupportedVectorId`.

## Upgrading

Change the version to `1.0.1`. Nothing else is needed.
