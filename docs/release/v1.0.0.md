# iqdb-eval v1.0.0 — Stable

**The evaluation harness is committed.** v1.0.0 delivers the complete harness —
correct recall@k against an exact oracle, latency percentiles and throughput, and
TEXMEX SIFT-family dataset loaders — and freezes its public surface under the
SemVer 1.x guarantee: no breaking changes until 2.0. What you build against today
keeps compiling.

## What is iqdb-eval?

The evaluation harness of the iQDB vector database. Vector indexes live and die
by their numbers, and this crate makes iQDB's reproducible. It measures
**recall@k**, **latency percentiles**, and **throughput** for any index behind the
`iqdb-index` `Index` / `IndexCore` traits — `iqdb-flat`, `iqdb-hnsw`, `iqdb-ivf`,
or any future backend — and uses `iqdb-flat` as the exact oracle to compute true
top-k ground truth when none is supplied. It is the crate that already validated
the recall numbers the rest of the family ships.

## The 1.0 surface

```rust
use iqdb_eval::{build_index_from_base, latency, recall_at_k_vs_oracle, LatencyConfig};
use iqdb_flat::{FlatConfig, FlatIndex};
use iqdb_types::{DistanceMetric, SearchParams};

# fn main() -> Result<(), iqdb_eval::EvalError> {
let base: Vec<Vec<f32>> = vec![vec![0.0, 0.0], vec![3.0, 4.0], vec![1.0, 1.0]];
let queries: Vec<Vec<f32>> = vec![vec![0.5, 0.5]];
let metric = DistanceMetric::Euclidean;

let target: FlatIndex = build_index_from_base(FlatConfig, 2, metric, &base)?;
let oracle: FlatIndex = build_index_from_base(FlatConfig, 2, metric, &base)?;
let params = SearchParams::new(2, metric);

let recall = recall_at_k_vs_oracle(&target, &oracle, &queries, &params)?;
assert_eq!(recall.mean_recall, 1.0); // flat is exact

let lat = latency(&target, &queries, &params, &LatencyConfig::default())?;
assert!(lat.p50_us <= lat.p95_us);
# Ok(())
# }
```

The committed surface (frozen, recorded in `dev/ROADMAP.md`):

- **recall@k** — `recall_at_k`, `compute_ground_truth`, `recall_at_k_vs_oracle`.
- **Latency** — `latency` with `LatencyConfig`.
- **Construction** — `build_index_from_base` (generic over `iqdb_index::Index`).
- **Datasets** — `read_fvecs`, `read_ivecs`, `load_sift_dataset`, `SiftDataset`.
- **Reports** — `RecallReport`, `LatencyReport` (optional `serde`).
- **Errors** — `EvalError`, `Result`. **Const** — `VERSION`.

## Highlights

- **recall@k, done correctly.** Recall is measured against the *true* top-k from
  an exact `iqdb-flat` oracle (or a loaded `.ivecs` ground-truth set) — never
  approximated, because an approximated ground truth makes the metric meaningless.
- **Index-agnostic.** One generic surface measures any backend behind the
  `Index` / `IndexCore` traits; the same call works against flat, HNSW, and IVF.
- **Honest latency.** Build cost is excluded by construction (the index is
  borrowed), percentiles are nearest-rank (every reported value is an observed
  sample), and QPS is single-threaded and reproducible.
- **Standard datasets, no new dependencies.** Hand-rolled TEXMEX `.fvecs` /
  `.ivecs` readers cover the SIFT family (`SIFT1M`, `GIST1M`, `siftsmall`);
  datasets are read from local files, so the crate pulls in no network code.
- **One simple rule.** Build both indexes with `build_index_from_base` and the
  `VectorId::U64` row-index convention makes `.ivecs` ids line up with `search`
  results automatically.

## Why this is 1.0

Every Definition-of-Done criterion (`dev/DIRECTIVES.md` §7) is met:

- **Clean everywhere** — `fmt`, `clippy -D warnings` (default and all features),
  `test --all-features`, and `cargo doc -D warnings` pass on the CI matrix
  (Linux, macOS, Windows), on stable and the 1.87 MSRV.
- **Secure** — `cargo audit` + `cargo deny` clean; **zero `unsafe`**
  (`#![forbid(unsafe_code)]`); no `unwrap` / `expect` / `todo!` / `dbg!` in
  shipping code; every input validated, every allocation bounded; no method
  panics on hostile input (empty sets, `k == 0`, `k > corpus`, dimension and
  length mismatches, truncated dataset files all return a clean `Result`).
- **Correct** — recall@k is checked against the exact `iqdb-flat` oracle by
  example and by `proptest` (flat-vs-flat recall is always `1.0`; report and
  percentile fields are bounded and ordered), plus an opt-in real-corpus
  integration test on `siftsmall`.
- **Documented** — every public item carries a runnable rustdoc example; the
  README leads with the Tier-1 surface; `docs/API.md` covers the whole API; three
  runnable examples ship in `examples/`.
- **Benchmarked** — `criterion` benches cover the recall (precomputed and
  vs-oracle) and latency measurement loops.

`loom` is **not applicable**: the harness holds no shared state and has no
lock-free path — it borrows an already-built index and reads, so there is nothing
for a concurrency model checker to explore.

## Breaking changes

**None.** This is the first stable tag; the surface is now committed under the
1.x guarantee. (Since 0.1.0, which carried no domain logic, the placeholder `std`
feature was removed — the crate is `std`-only.)

## What's next (post-1.0, additive)

- Additional dataset formats (e.g. a GloVe text loader) would be additive
  functions, not a break.
- Deeper integration against `iqdb-eval` as the engine matures.
